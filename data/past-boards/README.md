# 往届理事会数据说明

本目录按协会两年一届的规则，以任期开始年份保存公开可查的往届理事信息。JSON 只记录能够从协会官网、会议官网、任职机构主页或个人履历交叉确认的信息，不以会议组委会名单代替协会理事会名单。

## 届次划分

- 2012、2014：任向实担任创会会长的两届任期。
- 2016、2018：李维任会长。公开报道明确记录他在 2019 年任会长，并称任向实为前任会长/终身名誉会长。
- 2020、2022：付志勇任会长。清华大学官方履历明确记录其自 2020 年起担任 ICACHI 会长。
- 2024：以协会官网当前理事会名单为准。

早期完整选举公报目前没有公开存档。因此，2012—2018 文件是“公开可确认名单”，不应解读为当届全部理事。2020 年文件以协会旧版组织架构页面及当时公开履历为基础；2022、2024 名单以协会官网公开名单为基础。若协会秘书处提供正式选举结果，应以正式结果替换。

## 维护规则

- `name` 使用“中文名 English Name”。
- `role` 必须使用组件支持的英文角色名称。
- `org` 优先记录任期当时的任职机构；无法确认历史机构时不擅自回填。
- 头像仅复用 `docs/public/images/board/` 中已有并能确认身份的文件。
- 新证据应优先采用协会正式选举公告、协会官网存档或当事人带年份的履历，并在本文件追加来源。
