ICACHI编者注 CHI16’作为人机交互领域盛会已结束两周。在小编所在的实验室，参加了今年CHI的博后老师也做了总结。尽管总结内容会因为个人研究兴趣不同而有所偏好，但管中窥豹，可见一斑，希望与大家分享。各位读者如果想分享您的CHI体验，欢迎您的来稿!

## 数字

- 3800人参加
- 50%第一次参加
- 200+篇文章
- 40+ 个Sessions
- 1200+人参加 lunch@chi
- 700+小时的志愿工作

## 趋势

- 人机交互研究群体迅速成长，研究范围也不断扩大，不断融合其他学科的研究内容，如网络技术、信号处理，甚至政治、经济、隐私安全等等。
- 人机交互研究热点：input and interaction（一直是热点，智能手表成为新的对象）fabrications，social computing and behaviors，health，behavioral change， user experience，modeling
- 人机交互与机器学习的结合可能成为潮流。Human-centered machine learning结合HCI和ML的方法去解决大数据安全、信息可视化、行为挖掘、定制化UI可能成为一个好的选择。

## 文章推荐

One-Dimensional Handwriting: Inputting Letters and Words on Smart Glasses

文章在Google glass上定义了多种一维手势，映射到二维的笔画，从而完成字符输入交互。文章来自清华大学，内容有趣，思路开阔。

DualKey: Miniature Screen Text Entry via Finger Identification

智能穿戴日益流行，智能手表首当其冲。文章在智能手表上实现输入操作，将两个字符放在一个虚拟按键上，当食指点击某按键，输入左侧字母；当中指点击，输入右侧字母。当然，通过传感器识别左右手指。

IJQwerty: What Difference Does One Key Change Make? Gesture Typing Keyboard Optimization Bounded by One Key Position Change from Qwerty

传统键盘不适合输入？如果键盘上某两个字母调换，会发生什么？请看毕小俊老师和翟树民老师的这篇文章。

Pre-Touch Sensing for Mobile Interaction

来自微软的黑科技！文章通过self-capacitance touchscreen实现在触摸屏上悬浮操作，虽然微软手机卖的不好，但是黑科技多啊！

Local Standards for Sample Size at CHI

一篇号称人机交互领域都要看的文章！具体分析了CHI 2014中文章实验样本数量，也为我们实验设计带来新的角度。
